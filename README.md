## 1 Неотличимо от оригинала

Здесь для примера мы воспользуемся данными [дифференциальной экспрессии генов](https://ru.wikipedia.org/wiki/%D0%9A%D0%BE%D0%BB%D0%B8%D1%87%D0%B5%D1%81%D1%82%D0%B2%D0%B5%D0%BD%D0%BD%D1%8B%D0%B9_%D0%B0%D0%BD%D0%B0%D0%BB%D0%B8%D0%B7_%D1%8D%D0%BA%D1%81%D0%BF%D1%80%D0%B5%D1%81%D1%81%D0%B8%D0%B8_%D0%B3%D0%B5%D0%BD%D0%BE%D0%B2). В самом обычном случае, производится РНК-секвенирование разных образцов, после чего, выравнивая РНКу, люди получают сколько прочтений пришлось на каждый ген (в штуках, counts). Далее делается два относительно хитрых шага - нормализация и статистическое сравнение образцов. Их содержание - не суть данного задания, у вас еще будет проект на практикуме по РНК-секу. Здесь мы просто заранее научимся оформлять соотвествующие графики. В репозитории вы можете найти два файла: 
 
- `DE_data_1.tsv` - это уже нормализованные count'ы прочтений
- `DE_data_2.gz` - это таблица статистического сравнения анализа диффэкспрессии

Данные ~~взяты с потолка~~ относятся к разным экспериментам. **Ваша задача** - в ноутбуке `HW9_Visualization.ipynb` построить графики максимально похожие на то что приложено в репозитории (`heatmap.png` и `volcano_plot.png`). Внизу есть чек-лист для сверки, чем ближе к референсу сделаете тем лучше. 


### 1.1 Heatmap 
      
Данные - `DE_data_1.tsv`. По горизонтали - образцы, по вертикали - гены. В качестве значений отображаются нормализованные count'ы которые уже даны в таблице. **Постройте heatmap только по 100 самым экспрессирующимся генам** (фильтруйте по суммарной экспрессии по всем образцам). Обратите внимание на то, что образы проаннотированы цветами в верхней части heatmap. Тут возможно придется подольше подумать чтобы смочь так сделать. Если не сможете - оставьте без этого. Цвета можете выбрать какие хотите, но если что у меня тут `['#0099CC',  '#CCFFCC', '#66CCFF', '#7247D7', '#8D6DD7']` и цветовая схема `mako`. Также при желании можете поиграться с методом кластеризации, у меня тут `ward`. 


### 1.2 Volcano plot
   
Данные - `DE_data_2.gz` (pandas умеет открывать`.gz` файлы, поэтому разжимать их не обязательно). По оси X отложен logFC (Logarithmic Fold Change) - во сколько раз изменилась экспрессия гена в степенях двойки. По оси Y откладывается уровень значимости данных изменений в виде отрицательного десятичного логарифма p-value (с поправкой на множественное сравнение). Данные уже предобработаны, считать p-value и брать логарифмы не надо, просто используйте колонки logFC и log_pval.
